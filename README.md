## Overview

A Python application that retrieves and displays current weather information from the OpenWeatherMap API.

## Features

- 🌤️ City weather search
- 🌡️ Current conditions display
- 🔌 OpenWeatherMap integration
- 🐍 Python app structure

## Tech Stack

- Python
- Flask
- OpenWeatherMap API
- Gunicorn

## Getting Started

1. `python -m venv venv`
2. `source venv/bin/activate`
3. `pip install -r requirements.txt`
4. `python src/app.py`

## Usage

Run locally, open the app in a browser, and search for weather by city.
